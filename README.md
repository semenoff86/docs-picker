# Подбор документов для микрозайма

Виджет для сайта: посетитель отвечает на вопросы о сумме займа, способе подачи, форме бизнеса, налогообложении, обеспечении и других условиях. По ответам собирается перечень документов, которые нужно подготовить для заявки на микрозайм.

Модуль рассчитан на встраивание в сайт на 1С-Битрикс отдельной страницей.
